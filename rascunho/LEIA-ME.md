# rascunho/

Aqui vale tudo: notebook, script copiado, teste rápido. O conteúdo desta pasta não vai para o git
(só este arquivo vai).

Uma regra: **nada daqui é citado**. Número, figura ou tabela que nasceu aqui não entra no texto.

Quando uma ideia der certo, ela é promovida:

1. o que mudou vira parâmetro em `protovm/`, com valor padrão igual ao comportamento atual;
2. o experimento ganha uma ficha em `experimentos/` e, se for treino, um YAML em `configs/`;
3. commit;
4. roda de novo por `scripts/`. O número do texto é o dessa segunda execução.

Toda sexta a pasta é esvaziada: o que não foi promovido é apagado.
